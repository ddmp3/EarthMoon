# EarthMoon wiki (source)

Long-form material that the short docs in `docs/` summarize: data inventories, method experiments, run reports, history. This folder is the source of truth; the GitHub wiki is a mirror built by `tools/publish_wiki.sh` (task T02). Do not edit the GitHub wiki by hand.

| Folder | Content | Written by |
|---|---|---|
| `data/` | Lunar, Martian and Earth data inventories | T10, T11, T12 |
| `methods/` | Profiles, parameters, sampling, comparison, mapping | T20 to T26 |
| `runs/` | Reports of computation runs, with hashes and numbers | T40 onwards |
| `ui/` | Interface specifications | T26 |
| `v2/` | Full v2 scientific documents, unchanged | T02 |
| `baseline.md` | Quality baseline before v3 | T01 |
