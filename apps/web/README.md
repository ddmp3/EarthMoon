# Web front end

React + TypeScript + Vite + Leaflet + zustand. The interface opens in English (Space Apps submission requirement); an EN | FR switch in the top bar offers French. The choice is kept in the browser, and `?lang=fr` in the address selects French. French texts live in `src/i18n.ts` (interface) and `src/content-fr.ts` (site names, parameters, limits, sources); the API and the data stay in English.

```bash
npm ci
npm run dev            # http://localhost:5173, expects the API on http://localhost:3001 (VITE_API_URL to change it)
npm run build && npm run lint && npm test   # or, from the repository root: tools/check.sh web
npm run generate:api   # regenerate src/api-schema.ts after any change to ../api/openapi.yaml
```

## Screens

- **Home** (`src/components/Home.tsx`): full-bleed Artemis II photograph, then the four missions as cards, each with a real NASA photograph.
- **Mission** (`src/components/Mission.tsx`): illustrated ranking, NASA Blue Marble map (GIBS), filters, and the free-criteria builder.
- **Site card** (`src/components/SiteDetail.tsx`): Earth ↔ Moon crossfade at the same scale with lunar-like slopes highlighted, a single scorecard table (Earth value, lunar reference, match, verdict, source, then what Earth cannot reproduce), and a radar profile, and an assessment block (confidence, data coverage with the total range, hard requirements, explanation).
- **v3 in the missions** (`src/v3/`): robotics uses scenario B and colony scenario A. Each has an environment picker, the coverage overlay (on by default, six SVG patterns with their land share), a validity line (`/api/v3/status`), a v3 mark on each ranked site and a "Discovered zones" tab. The map shows typicality tiles to zoom 7, then 5 km cells. Zone card, comparison of 2 to 4 zones, provenance, and Data and method are available. The site card has "Our v3 data at this place" (`/api/v3/sites`). Free criteria adds a v3 search of the whole Earth in the map view (`/api/v3/query`). Calibration says that scenario C is not computed yet. API texts are translated in `src/v3/content.ts`.

Shareable addresses: `#colony`, `#colony/tunnunik` (`#discover` opens free criteria); `?fade=60` sets the initial Earth ↔ Moon crossfade.

## Images

- `public/img/`: NASA photographs (credits in `public/img/credits.json`). No AI-generated imagery.
- `public/sites/<id>/`: satellite view, shaded relief and lunar twin of each site, generated by `tools/precompute/site_visuals.py` (`manifest.json` lists sources and twin coordinates). Regenerate after changing `data/candidates.json`.

## Security headers

`nginx/default.conf.template` (Docker) and `staticwebapp.config.template.json` (Azure) set the content security policy: scripts and fonts from the site only, images from the site and NASA GIBS, API calls to the configured API origin.
