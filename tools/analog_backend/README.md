# analog_backend — first analysis prototype (reference, not part of the app)

An early Python prototype written before the current architecture. **It is not part of the application** (the API is Node/TypeScript, see `docs/architecture.md`). It is kept as a reference and for an independent check of the ranking.

Pipeline: input audit → ingestion → observation-gap detection → Earth/Moon similarity → JSON export. It computes slope, roughness and shadow fraction on a common geometric basis (Earth and Moon), compares thermal variables by planet-specific quantile, and produces a multi-criteria similarity index (MCSI).

## Differences from the current project

- Inputs: NLDAS (continental US) and RCM (SAR). The project uses NASA POWER, Copernicus DEM, MODIS, USGS and GVP.
- It processes full grids; the project scores a list of candidate points.
- Score: weighted distance + cosine to a lunar target vector; the project uses target interval + tolerance + weight (`docs/scenarios.md`).
- `schema/analogs.ts` is exploratory, **not** the API contract.

## Tests

`tests/test_smoke.py` passes on **synthetic** data generated by `tests/make_fixtures.py`. The pipeline has not been run on real LRO, NLDAS or RCM data.
